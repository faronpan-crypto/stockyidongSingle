# 📋 需求文档：大跌/大涨日历记录与预警系统

**文件名：** `crash_rally_calendar.py`
**对应Tab名称：** `🗓️ 大跌大涨日历`
**依赖数据库表：** `crash_rally_events` 表

---

## 一、功能定位

记录A股历史每次**大幅波动日期**（暴跌/暴涨），标注触发原因，提炼**提前信号**，形成可查询的日历知识库，并能在盘中实时预警——**让你以后能提前躲开**。

---

## 二、核心功能模块

### 2.1 历史事件库（数据库）

**表 `crash_rally_events`**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PRIMARY KEY | 自增ID |
| event_date | TEXT | 事件日期（YYYY-MM-DD） |
| event_type | TEXT | `crash` 暴跌 / `rally` 暴涨 |
| index_name | TEXT | 涉及的指数（上证/创业板/科创50/深证） |
| index_pct | REAL | 当日涨跌幅（%） |
| magnitude | TEXT | `刹跌`(>-3%) / `大跌`(-5%~-3%) / `崩盘`(<-5%) / `小涨`(3-5%) / `大涨`(5-8%) / `暴涨`(>8%) |
| trigger | TEXT | 触发原因 |
| trigger_detail | TEXT | 原因详细描述 |
| leading_signals | TEXT | 提前信号 |
| signal_days_before | TEXT | 信号提前几天出现 |
| recovery_days | INTEGER | 多少日后收复失地（-1=未收复） |
| max_recover_pct | REAL | 最大反弹幅度 |
| notes | TEXT | 备注 |
| source_urls | TEXT | 参考链接，多个用`\|`分隔 |
| related_stocks | TEXT | 关联持仓股票 |
| created_at | TEXT | 记录创建时间 |

### 2.2 触发原因分类体系

**暴跌触发**：外围冲击/政策收紧/汇率贬值/流动性危机/业绩地雷/行业崩塌/技术破位/情绪高潮/未知

**暴涨触发**：政策利好/资金涌入/技术修复/外围传导/情绪修复/题材爆发

### 2.3 提前信号体系

| 信号类型 | 描述 | 量化标准 |
|---|---|---|
| 涨跌家数极端 | 上涨/下跌家数极度失衡 | 涨跌家数比>10:1 |
| 量能异常 | 大幅放量 | 量比>2.0 |
| 北向连续流出 | 连续3日北向净卖出超百亿 | 3日累计<-300亿 |
| MA乖离率过大 | 指数离MA20乖离>5% | BIAS20>5% |
| RSI超买/超卖 | RSI>80或RSI<30 | RSI14>80或<30 |
| 融资余额拐点 | 融资余额大幅下降 | 3日减少>500亿 |
| 盘口异动 | 早盘10:30前跌幅超1% | 10:30指数<昨收-1% |
| 情绪高潮/冰点 | 涨停/跌停家数极端 | 涨停>150或跌停>100 |
| 美股期货大跌 | A股盘前期指持续走低 | 纳指期指<-2% |
| 期指贴水扩大 | IH/IF贴水加深 | 贴水>20点 |
| 期权put/call比 | Put成交量异常放大 | PCR>1.5 |
| 龙头股闪崩 | 龙头股莫名其妙大跌 | 当日>3只龙头闪崩 |
| 新股破发率 | 新股大面积破发 | 破发率>50% |

### 2.4 五大核心功能Tab

#### Tab A：历史事件记录（新增/编辑/批量导入）
- 新增事件：输入日期 → 自动拉当日指数涨跌幅 → 选事件类型 → 选触发原因 → 填写详情 → 标记信号
- 批量导入：从Excel/csv批量导入历史记录
- 编辑已有事件：修改/补充信息
- 关联股票：某日暴跌关联到持仓股票代码

#### Tab B：事件日历视图
- 年历/月份视图，以颜色热力图展示（红=暴跌，蓝=暴涨）
- 点击某日显示该日事件摘要卡片
- 支持按年/月筛选
- 导出当月/当年事件报告为Markdown

#### Tab C：信号回测/规律发现
- 从历史事件库中提炼规律
- 统计每个信号的历史命中率
- 提炼"高胜率预警信号组合"

#### Tab D：盘中实时预警监控
- 读取今日实时数据，检测是否触发"暴跌/暴涨前兆信号"
- 达到预警阈值时弹窗+写入日志
- 预警等级：🔴红色/🟡黄色/🟢绿色
- 阈值配置面板可调

#### Tab E：🔮 涨跌预测（情绪周期+历史相似+节日效应）
- 读取情绪周期JSON (stage/emo_score)
- 历史相似情境匹配 (同情绪阶段+同触发信号)
- 节日效应统计 (中秋/春节/国庆等节假日前后涨跌)
- 综合预测结论 (偏涨/偏跌/置信度/操作建议)

### 2.5 配套工具
- 数据初始化：内置历史重大事件种子数据（2018-2026年，41条）
- 报告导出：月度/年度总结报告（Markdown）

## 四、技术要求

1. **数据库**：SQLite，路径 `~/.qclaw/stock_analysis.db`，表 `crash_rally_events`
2. **GUI**：tkinter + ttk.Notebook，5个子Tab
3. **数据抓取**：requests.Session + 重试模式
4. **字体/样式**：SimHei/Microsoft YaHei
5. **多线程**：threading.Thread，GUI更新用 root.after()
6. **错误处理**：suppress_stderr() / suppress_all_errors() 装饰器，异常跳过不停止
7. **数据持久化**：自动写入SQLite，支持导出csv/Markdown
8. **预警弹窗**：messagebox.showwarning() / simpledialog

## 五、调用方式
