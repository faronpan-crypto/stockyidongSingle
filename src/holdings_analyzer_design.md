# 持仓诊断自动化 - 斯东克任务设计

## 目标
每日收盘（15:10），自动导出持仓数据 → 多维度诊断分析 → 微信+小程序推送报告。

## 架构流程
```
cron: 15:10 周一至周五
  │
  ├─ step1: python3 stockyidong_export.py     (导出持仓到 .txt)
  │
  └─ step2: python3 holdings_analyzer.py      (斯东克多维度分析)
        │
        ├─ 读取导出的持仓 .txt
        ├─ 与今日涨停/强势池交叉比对
        ├─ 多维度评分（共振度/封板强度/板块联动/资金流向）
        ├─ 排序输出 Markdown 报告
        │
        └─ 推送：wechat-access (微信) + announce (webchat)
```

## 持仓标签页说明
| 标签页 | 数量 | 说明 |
|--------|------|------|
| 龙头股 | 80只 | 核心自选/重点标的 |
| 15Min | 40只 | 短线异动观察 |
| 同花顺 | 80只 | 辅助参考池 |

## 分析维度（多维度评分体系）
1. **共振度**：该持仓出现在多少个选股策略中（来自 auto_screener.py 的 7 大策略）
2. **封板强度**：涨停股封单金额 / 成交额比例
3. **板块联动**：所属板块今日整体表现
4. **连板预期**：是否在连板梯队中（2-4板）
5. **炸板风险**：今日是否炸板，炸板次数
6. **换手健康度**：换手率是否合理（5-25% 区间为健康）

## 定时任务配置
- **触发时间**：`10 15 * * 1-5`（周一至周五 15:10）
- **执行者**：`agent-8e17987b`（斯东克）
- **推送方式**：`announce` → webchat + wechat-access 自动送达
- **超时设置**：180秒

## 关键依赖
- `stockyidong_export.py`（已有）
- `auto_screener.py`（已有，产生涨停池数据）
- `holdings_analyzer.py`（新建，斯东克核心分析引擎）
- `wechat-access` plugin（已有，已连接）

## 风险控制
- 若持仓为0，输出"今日无持仓数据"
- 若网络异常，输出"市场数据获取失败，请稍后手动查询"
- 所有结论前加"⚠️ 本分析仅供参考，不构成投资建议"
